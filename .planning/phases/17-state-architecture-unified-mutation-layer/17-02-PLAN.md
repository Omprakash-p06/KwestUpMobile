<objective>
Decouple the `App.js` monolith into domain context providers (`TaskContext`, `VaultContext`, `BillingContext`, `BirthdayContext`), eliminate prop-drilling in `AppNavigator.js`, and add automatic foreground synchronization via `AppState`.

Purpose: Provide clean separation of concerns, eliminate the 50-prop parameter explosion across screens, and ensure that tasks modified via home-screen widgets automatically synchronize with the active app on foreground resume.
Output: Domain context providers in `src/context/`, unit test suite `__tests__/unit/taskContext.test.js`, refactored `AppNavigator.js`, and streamlined `App.js`.
</objective>
