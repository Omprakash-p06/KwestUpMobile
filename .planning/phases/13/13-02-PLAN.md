## Proposed Changes

---

### [MODIFY] `src/utils/billingStorage.js`
Extend the billing schema and add recurring bill helpers.

**Add to schema (recurringBills array):**
```js
recurringBills: [
  {
    id: string,
    name: string,           // "Netflix", "Electricity", "Rent"
    amount: number,
    category: string,
    dueDay: number,         // 1-31, day of month the bill is due
    notifyDaysBefore: number, // 0=on due date, 1=1 day before, 3=3 days before, 7=1 week before
    notificationIds: [],    // Expo notification IDs for cancellation
    lastPaidDate: string | null, // ISO date of last marked-as-paid
    active: boolean,
  }
]
```

**Add exported functions:**
- `addRecurringBill(bill)` — appends bill, schedules notifications, saves
- `deleteRecurringBill(id)` — cancels notifications, removes from array, saves
- `markBillPaid(id, paidDate)` — sets lastPaidDate, reschedules next month notification, saves
- `scheduleRecurringBillReminder(bill)` — calculates next due date from dueDay, calls expo-notifications scheduleNotificationAsync with trigger date, returns notification ID
- `cancelRecurringBillReminder(notificationIds)` — bulk cancels via Notifications.cancelScheduledNotificationAsync

### [MODIFY] `src/screens/BillingScreen.js`
Add two new sections to the existing scrollable layout (after Budget Envelopes, before Transaction Log).

#### Section D — Recurring Bills
- Vertical list of recurring bill cards
- Each card: bill name, amount, category chip, "DUE ON: {dueDay}th", notify badge (e.g. "3_DAYS_BEFORE")
- Right side: MARK PAID button (CustomButton compact variant) + trash delete

- Empty state: NO_RECURRING_BILLS_TRACKED
- FAB row: "＋ BILL" button opens AddRecurringBillModal

#### AddRecurringBillModal (inline in BillingScreen.js)
Fields:
- CustomTextInput: Bill name
- CustomTextInput: Amount (numeric keyboard)
- Category picker chips (same set as transactions)
- Day picker: horizontal number scroll (1-31) for dueDay
- Notify advance picker: ON_DAY | 1_DAY | 3_DAYS | 1_WEEK (CustomSegmentedButtons)
- CustomButton: ADD BILL

#### Section E — Analytics (Monthly Overview)
Replace or augment the existing Transaction Log header with a collapsible Analytics panel.

**Analytics panel contents:**
- Month selector (prev/next arrows + month label "JUL 2026")
- Donut-style category breakdown — rendered as segmented horizontal bar (no SVG dependencies)
  - Each segment is a View with flex proportional to spending share
  - Color-coded: Food=#ef4444, Transport=#f59e0b, Housing=#3b82f6, Health=#22c55e, Salary=#8b5cf6, Other=#94a3b8
- Category legend list below the bar: category name | spent | % of total
- Month-over-month change line: "vs last month: ▲14% more spending" or "▼8% less spending"

### [NEW] `src/utils/billingNotifications.js`
Dedicated notification helper for recurring bills (separates concerns from notifications.js).

**Exported functions:**
- `scheduleRecurringBillReminder(bill)`:
  - Calculates next due date for current or next month based on today vs dueDay
  - Schedules notification: title `🏦 Bill Due Soon!`, body `{name} (₹{amount}) is due on {date}`
  - Returns notification ID
- `cancelRecurringBillReminders(ids)`:
  - Calls Notifications.cancelScheduledNotificationAsync for each ID
