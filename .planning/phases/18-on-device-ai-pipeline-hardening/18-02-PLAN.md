## 1. Goal

Implement automatic context memory lifecycle management (background unloader, unmount cleanup, idle timeout) to eliminate native OOM risk, and build a resilient rule-based fallback pipeline so notes summarization, task extraction, and command parsing always succeed even when native LLM inference fails.

---

## 2. Tasks

### Task 1: Memory Lifecycle Management in `src/utils/aiService.js` & `src/components/AIAssistant.js`
- In `src/utils/aiService.js`:
  - Add `AppState` event listener that monitors `nextAppState`. When transitioning to `"background"` or `"inactive"`, automatically trigger `unloadModel()` to release native llama context.
  - Implement a configurable idle timer (default: 5 minutes):
    - Reset on every model access (`loadModel`, `summarizeNote`, `extractTasksFromNote`, `parseGlobalCommand`, `assistWriting`).
    - If no activity occurs for 5 minutes, automatically invoke `unloadModel()`.
  - Export `getModelContextStatus()` returning `{ isLoaded: boolean, isLoading: boolean }` for diagnostics.
- In `src/components/AIAssistant.js`:
  - Add `useEffect` cleanup hook that calls `unloadModel()` when the assistant unmounts.

### Task 2: Resilient Rule-Based Fallback Pipeline in `src/utils/aiService.js`
- Export pure heuristic fallback functions:
  - `extractTasksFromNoteHeuristic(noteContent)`:
    - Extracts `- [ ] Task title` and `- [x] Task title` markdown checklist items.
    - Extracts lines starting with `TODO:`, `Todo:`, `Action:`.
    - Extracts bullet points matching imperative action verbs (`Buy`, `Call`, `Send`, `Check`, `Review`, `Fix`, `Update`, `Create`, `Email`, `Prepare`, `Submit`, `Finish`, `Pay`, `Read`, `Write`).
    - Returns array of cleaned task title strings.
  - `summarizeNoteHeuristic(noteContent)`:
    - Extracts document title and markdown headings (`#`, `##`, `###`).
    - Extracts key leading sentences from non-empty paragraphs.
    - Returns clean bullet points (`• Header / Key Sentence`).
- Integrate fallbacks into:
  - `extractTasksFromNote(noteContent)`: If `loadModel` or `ctx.completion` fails, seamlessly call `extractTasksFromNoteHeuristic(noteContent)` and return results without throwing.
  - `summarizeNote(noteContent, onToken)`: If `loadModel` or `ctx.completion` fails, stream or return `summarizeNoteHeuristic(noteContent)` with clear indicator.
  - `parseGlobalCommand(command)`: Replace raw UTC `new Date()` with local date authority from `dateUtils.js`.
