### [NEW] `src/utils/billingStorage.js`
Central billing persistence module. All billing data stored inside the shared `kwestup_data_v6.0` AsyncStorage blob under key `billing`.

**Schema:**
```js
billing: {
  transactions: [
    {
      id: string,            // Date.now().toString()
      type: "income" | "expense",
      amount: number,        // Stored in base unit (e.g. INR rupees)
      category: string,      // "Food", "Transport", "Salary", etc.
      description: string,
      date: string,          // ISO date string "YYYY-MM-DD"
      createdAt: string,     // ISO timestamp
    }
  ],
  budgets: [
    {
      id: string,
      category: string,
      limit: number,         // Monthly budget ceiling for this category
      period: "monthly",     // v1 only monthly
    }
  ],
  recurringBills: [],        // Populated in Plan 13-02
  currency: "INR",           // Default currency symbol
}
```

**Exported functions:**
- `loadBillingData()` - reads billing blob from AsyncStorage, returns default empty state if absent
- `saveBillingData(billingState)` - serializes and saves billing blob
- `addTransaction(tx)` - appends and saves
- `deleteTransaction(id)` - filters and saves
- `upsertBudget(budget)` - creates or updates by category, saves
- `deleteBudget(id)` - removes and saves
- `getSpendingByCategory(transactions, month)` - returns {category: totalSpent} map for a given "YYYY-MM" month string

### [NEW] `src/screens/BillingScreen.js`
Primary finance screen. Uses the existing industrial UI aesthetic (JetBrains Mono, sharp borders, LiquidGlassCard panels).

**Layout (3 top-level sections, scrollable):**

#### Section A — Summary Header Card
- NET_BALANCE display: income - expenses this month in large monospace font
- Two sub-stats side by side: INCOME_THIS_MONTH | EXPENSES_THIS_MONTH
- Active badge showing current month (e.g. JUL_2026)

#### Section B — Budget Envelopes
- Horizontal scroll row of budget envelope cards (one per category)
- Each card shows: category name, spent/limit bar, remaining amount
- Progress bar fills with primary color; turns error color if overspent (spent > limit)
- Tap "+" button opens AddBudgetModal

#### Section C — Transaction Log
- Segmented tab control: ALL | INCOME | EXPENSES
- Filtered list of transaction rows sorted newest-first
- Each row: left icon (up arrow=income / down arrow=expense in themed color), description + category tag, date, amount
- Long-press a row for deletion confirmation
- Empty state label: NO_TRANSACTIONS_LOGGED
- FAB "+" button (bottom-right) opens AddTransactionModal

#### AddTransactionModal (inline in BillingScreen.js)
Fields:
- CustomSegmentedButtons: INCOME | EXPENSE toggle
- CustomTextInput: Amount (numeric keyboard)
- CustomTextInput: Description
- Category picker: horizontal flat chips (Food, Transport, Housing, Health, Salary, Other)
- CustomDatePickerModal: Transaction date (defaults to today)
- CustomButton: SAVE TRANSACTION

#### AddBudgetModal (inline in BillingScreen.js)
Fields:
- Category picker (same chips as transaction)
- CustomTextInput: Monthly limit amount
- CustomButton: SET BUDGET

**Props received from AppNavigator:**
```js
billingData,        // { transactions, budgets, recurringBills, currency }
setBillingData,     // state setter
currentTheme,
showConfirmation,
```
