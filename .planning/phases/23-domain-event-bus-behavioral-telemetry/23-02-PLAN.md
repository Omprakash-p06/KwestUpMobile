<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| React Component state to EventBus | Mutator callbacks emit events; must not perform side-effects inside state reducer functions |
| Android Widget headless worker to EventBus | Background thread must emit lightweight payloads and avoid memory leaks |
| Context error paths to Logger | Error logs must route to structured logger without exposing user financial or personal details |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-23-06 | Tampering | React setState double-emission | medium | mitigate | Emit events in event handlers and callbacks outside setState functional updater closures |
| T-23-07 | Information Disclosure | BillingContext logging | medium | mitigate | Replace raw `console.error` with `logger.error`, avoiding logging transaction titles or amounts |
| T-23-08 | Denial of Service | widget Binder memory | low | mitigate | Keep widget event payloads minimal (id, action, target) without serializing full app state |
| T-23-09 | Repudiation | audit trace gap | low | mitigate | Event bus records `source: 'app' \| 'widget'` on every emitted event for deterministic auditability |
</threat_model>
