## 1. Goal

Secure the on-device AI model download and loading pipeline by pinning the download URL to an exact Git commit, declaring cryptographic verification constants, implementing pre-load integrity verification with automated corruption cleanup, and replacing the spin-wait initialization mutex with a Promise-based lock.

## 2. Tasks

### Task 1: Model Pinning & Cryptographic Constants in `src/utils/aiService.js`
- Update `MODEL_DOWNLOAD_URL` to point to immutable commit `9217f5db79a29953eb74d5343926648285ec7e67`:
  `https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/resolve/9217f5db79a29953eb74d5343926648285ec7e67/qwen2.5-0.5b-instruct-q4_k_m.gguf`
- Export authoritative constants:
  - `MODEL_PINNED_COMMIT = "9217f5db79a29953eb74d5343926648285ec7e67"`
  - `MODEL_EXPECTED_SHA256 = "74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db"`
  - `MODEL_EXPECTED_SIZE = 491400032`
- Export `computeSha256(data)` utility function using `crypto-js/sha256` for string/buffer cryptographic verification.

### Task 2: Implement Pre-Load `verifyModelIntegrity`
- Export `verifyModelIntegrity(filePath = MODEL_PATH, customValidator = null)`:
  - Checks if file exists using `FileSystem.getInfoAsync(filePath)`.
  - Validates `fileInfo.size === MODEL_EXPECTED_SIZE`.
  - If a `customValidator` is provided, executes `customValidator(filePath)` for hash checking.
  - If file size does not match or file is corrupted:
    - Logs descriptive warning.
    - Deletes corrupted file using `FileSystem.deleteAsync(filePath, { idempotent: true })`.
    - Returns `false`.
  - Returns `true` only if verification passes cleanly.
- Update `isModelDownloaded` to use `verifyModelIntegrity`.

### Task 3: Replace Busy-Wait Mutex with Promise-Based Initialization Lock in `loadModel`
- Eliminate `let _isInitializing = false` and the spin-wait loop `while (_isInitializing) { await sleep(100); }`.
- Introduce `let _initPromise = null`.
- If `_llamaContext` is already loaded, return immediately.
- If `_initPromise` is in-flight, return `_initPromise` so all concurrent callers coalesce cleanly onto the single pending Promise.
- In the initialization block:
  - Await `verifyModelIntegrity()`. If false, throw descriptive error.
  - Call `initLlama(...)` with existing optimized parameters (`n_ctx: 2048`, `n_threads: 2`, `n_gpu_layers: 0`, `no_gpu_devices: true`).
  - In `finally`, reset `_initPromise = null`.

### Task 4: Unit Test Suite for Plan 01 in `__tests__/unit/aiService.test.js`
- Create `__tests__/unit/aiService.test.js`.
- Add tests for:
  - Pinned commit and URL verification.
  - `computeSha256` correctness.
  - `verifyModelIntegrity`: passes on exact size (`491,400,032`), fails and deletes on truncated size (`400,000,000`).
  - Concurrent `loadModel` calls sharing the same promise without calling `initLlama` twice.
