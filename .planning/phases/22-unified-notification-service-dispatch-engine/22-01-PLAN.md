## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JS scheduler to native notification manager | Trigger payloads cross into OS-owned delivery; malformed content must not reach the user |
| AsyncStorage history to policy evaluator | Persisted history is untrusted input — corrupt JSON must not crash or bypass policy |
| Import pipeline to bill scheduler | Imported bill data is untrusted — malformed amounts must not fabricate financial alerts |
