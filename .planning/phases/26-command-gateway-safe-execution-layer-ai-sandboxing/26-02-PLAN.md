  <action>
    Create `src/commands/aiSandbox.ts`:
    1. **Input Sanitization (`sanitizeAiPayload`):**
       - Takes untrusted raw AI input (parsed JSON or raw object from LLM output).
       - Recursive object sanitization:
         - Recursively strips prototype pollution keys (`__proto__`, `constructor`, `prototype`).
         - Validates that values are plain JSON primitives (strings, numbers, booleans, plain arrays, plain objects).
         - Rejects functions, regexes, symbols, and dates.
         - Strips attempts to inject storage keys (`kwestup_*`) or path traversal sequences (`../`, `file://`, `/`).
       - Enforces PII and sensitive data masking in error and logging outputs according to `SYS_PII_LOG_REDACT_001`.
    2. **Destructive Command Gate:**
       - If action is `DELETE_HABIT` or `ARCHIVE_HABIT`, checks `options?.confirmed === true`.
       - If not confirmed, refuses execution immediately with `{ success: false, requiresConfirmation: true, message: 'Action requires user confirmation before proceeding' }`.
    3. **Sandboxed Dispatcher (`executeAiCommand`):**
       - Generates a crypto-random monotonic `idempotencyKey` if not supplied: `cmd_ai_${Date.now()}_${Math.random().toString(36).slice(2, 9)}`.
       - Wraps sanitized payload into `DispatchedCommand` with `actor: 'ai'`.
       - Dispatches through `executeCommand` in `commandExecutor.ts`.
       - Zero-escape invariant: the AI sandbox NEVER invokes `AsyncStorage`, `FileSystem`, or `Notifications` directly. All state mutations must flow through the Command Gateway.
  </action>
