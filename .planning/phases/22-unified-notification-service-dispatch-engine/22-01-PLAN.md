Create `src/services/notificationService.ts`:
1. **Types & Constants**:
   - Import types and defaults from `src/services/types.ts`: `AndroidNotificationChannel`, `ScheduledNotificationDescriptor`, `BehavioralNotificationPolicy`, `DEFAULT_BEHAVIORAL_NOTIFICATION_POLICY`.
   - Import `Platform`, `Alert` from `'react-native'`, `* as Notifications` from `'expo-notifications'`, `AsyncStorage` from `'@react-native-async-storage/async-storage'`, `logger` from `'../utils/logger'`, and `getLocalDateString` from `'../utils/dateUtils'`.
   - Export `ANDROID_NOTIFICATION_CHANNELS: Record<string, AndroidNotificationChannel>` with:
     - `BEHAVIOR_CUES`: `id: 'kwestup_behavior_cues'`, `name: 'Habit & Behavior Cues'`, `importance: 4`, `vibrationPattern: [0, 250, 250, 250]`.
     - `DAILY_TASKS`: `id: 'kwestup_daily_tasks'`, `name: 'Daily Tasks & Reminders'`, `importance: 4`, `vibrationPattern: [0, 250, 250, 250]`.
     - `BIRTHDAYS`: `id: 'kwestup_birthdays'`, `name: 'Birthdays & Celebrations'`, `importance: 3`.
     - `BILLING`: `id: 'kwestup_billing'`, `name: 'Bills & Subscriptions'`, `importance: 3`.
     - `SYSTEM`: `id: 'kwestup_system'`, `name: 'System & Sync'`, `importance: 2`.
   - Define `NOTIFICATION_HISTORY_KEY = 'kwestup_notification_history_v1'`.
2. **Channel Initialization & Permissions**:
   - `Notifications.setNotificationHandler({ handleNotification: async () => ({ shouldShowAlert: true, shouldPlaySound: true, shouldSetBadge: true }) })`.
   - `export async function initNotificationChannels(): Promise<void>`:
     If `Platform.OS === 'android'`, call `Notifications.setNotificationChannelAsync(channel.id, ...)` for each channel.
   - `export async function requestNotificationPermissions(): Promise<string>`:
     Calls `requestPermissionsAsync` with Android/iOS branching, showing `Alert.alert` if denied, and returns status string.
3. **Deterministic Policy Evaluation**:
   - Export interface `PolicyEvaluationResult`: `{ allowed: boolean; adjustedTriggerDate?: Date; reason: 'ok' | 'quiet-hours' | 'daily-cap' | 'min-gap' | 'dedup' | 'user-opt-out' }`.
   - Export function `evaluateNotificationPolicy(targetDate: Date, history: NotificationHistoryEntry[], opts?: { payloadKey?: string; category?: 'critical' | 'behavioral' }, policy?: BehavioralNotificationPolicy, now?: Date): PolicyEvaluationResult`:
     - If `policy.userOptOut && opts?.category !== 'critical'` -> return `{ allowed: false, reason: 'user-opt-out' }`.
     - Quiet hours check: Convert `policy.quietHoursStart` and `policy.quietHoursEnd` (default `22:00` and `08:00`) to minute-of-day. If `targetDate` falls in `[start, end)` (handling midnight wrap where `start > end`), calculate `deferredDate` anchored to `08:01` wall-clock:
       - If target hour `>= 22`, defer to `08:01` on next day.
       - If target hour `< 8`, defer to `08:01` on same day.
       - Return `{ allowed: true, adjustedTriggerDate: deferredDate, reason: 'quiet-hours' }`.
     - Daily cap check: If `opts?.category !== 'critical'`, filter `history` for entries matching `getLocalDateString(targetDate)`. If count `>= policy.maxPerDay` (default 3), return `{ allowed: false, reason: 'daily-cap' }`.
     - Min gap check: If `opts?.category !== 'critical'`, check if any history entry is within `policy.minGapMinutes` (default 90) of `targetDate`. If so, return `{ allowed: false, reason: 'min-gap' }`.
     - Deduplication check: If `opts?.payloadKey`, find any history entry with matching `payloadKey` within `policy.deduplicationWindowMinutes` (default 30). If found, return `{ allowed: false, reason: 'dedup' }`.
     - Otherwise return `{ allowed: true, reason: 'ok' }`.
4. **History Storage**:
   - `getNotificationHistory(): Promise<NotificationHistoryEntry[]>`: Loads from `AsyncStorage`, prunes entries older than 48 hours.
   - `recordNotificationDispatch(entry: NotificationHistoryEntry): Promise<void>`: Appends entry, prunes old entries, saves to `AsyncStorage`.
5. **Schedulers**:
   - `scheduleNotification(descriptor: ScheduledNotificationDescriptor, policy?: BehavioralNotificationPolicy): Promise<string | null>`
   - `scheduleDailyTaskReminder(task: { id: string; name: string; time: string }): Promise<string | null>`: Validates HH:MM format, uses `DAILY_TASKS` channel.
   - `scheduleDueDateReminder(task: { id: string; title?: string; name?: string; dueDate: string; description?: string }): Promise<string | null>`: Skips past due dates, schedules future ones.
   - `scheduleBirthdayReminders(birthday: { id?: string; name: string; birthDate: string; remindAtTime?: string; advanceReminder?: string }): Promise<string[]>`: Robust parsing, Feb 29 leap year policy (Feb 28 in non-leap year), advance reminders, atomic rollback on failure.
   - `scheduleBillReminder(bill: { id?: string; name: string; amount: number; dueDay: number; notifyDaysBefore?: number }, currency?: string): Promise<string | null>`: Calculates next due date, uses `BILLING` channel.
6. **Cancellations**:
   - `cancelNotification(notificationId: string): Promise<void>`
   - `cancelNotifications(notificationIds: string[]): Promise<void>`
   - `cancelAllNotifications(): Promise<void>`
7. **Privacy Invariant**:
   - Use `logger.info` / `logger.error` only with safe metadata (e.g. `{ channelId, notificationId, triggerHour, triggerMinute }`). Never log raw task names, birthday names, or amounts.
</action>
