## 1. Goal

Eliminate debug log pollution in production builds and establish an environment-aware structured logging utility (`logger.js`) with an in-memory 50-entry circular ring-buffer. High-frequency `console.log` statements will be stripped during production builds via Babel AST transformation while preserving operational `console.warn` and `console.error` diagnostics.

---

## 2. Tasks

### Task 1: Install Babel Console Transform & Update `babel.config.js`
- Install `babel-plugin-transform-remove-console` as a `devDependency`.
- Update `babel.config.js` to dynamically add `["transform-remove-console", { exclude: ["error", "warn"] }]` when `process.env.NODE_ENV === "production"`.
- Ensure tests and local development (`process.env.NODE_ENV !== "production"`) remain unaffected.

### Task 2: Create Runtime Structured Logger (`src/utils/logger.js`)
- Implement `src/utils/logger.js` exposing:
  - `debug(message, ...details)`: Silenced in production (`!__DEV__`); emits in development and pushes breadcrumb.
  - `info(message, ...details)`: Silenced in production (`!__DEV__`); emits in development and pushes breadcrumb.
  - `warn(message, ...details)`: Always emits to `console.warn` and pushes breadcrumb.
  - `error(message, ...details)`: Always emits to `console.error` and pushes breadcrumb.
  - `getRecentLogs()`: Returns an immutable snapshot copy of recent breadcrumbs (`{ timestamp, level, message, details }`).
  - `clearLogs()`: Resets the ring-buffer.
- Implement an in-memory 50-entry FIFO ring-buffer:
  - Guaranteed bounded memory footprint (never exceeds 50 entries).
  - Automatically evicts oldest breadcrumbs when capacity is reached.
  - Zero filesystem or persistent storage writes (pure in-memory).

### Task 3: Migrate Core Verbose Logs to Structured Logger
- Replace high-frequency emoji debug `console.log` calls with `logger.debug` or `logger.info` in:
  - `src/utils/storage.js` (cache clear, migration progress)
  - `src/utils/exportService.js` (archive export/import progress)
  - `src/utils/syncService.js` (sync handshakes and status)
  - `src/utils/aiService.js` (model verification, life cycle logs)
  - `src/context/TaskContext.js` (storage sync markers)
- Ensure all operational warnings and caught errors continue routing through `logger.warn` or `logger.error` to retain critical diagnostic signals.

### Task 4: Unit Test Suite for Structured Logger (`__tests__/unit/logger.test.js`)
- Author `__tests__/unit/logger.test.js`:
  - Verify `logger.debug` and `logger.info` are silenced when `__DEV__` is false and active when `__DEV__` is true.
  - Verify `logger.warn` and `logger.error` always delegate to underlying `console.warn` and `console.error`.
  - Verify ring-buffer limits to 50 items and enforces FIFO eviction on overflow.
  - Verify `logger.getRecentLogs()` returns timestamps in ISO 8601 format and does not leak mutable internal array references.
  - Verify `logger.clearLogs()` cleanly empties the buffer.
  - Verify `babel.config.js` properly configures the console removal plugin under production environment flags.
