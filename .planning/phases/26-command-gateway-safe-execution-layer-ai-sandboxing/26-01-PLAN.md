    1. Create `src/commands/commandValidator.ts`:
       - Define supported capability set: all 11 `CommandAction` types (`CREATE_HABIT`, `UPDATE_HABIT`, `DELETE_HABIT`, `LOG_HABIT`, `START_RECOVERY`, `DISMISS_INTERVENTION`, `ADJUST_DIFFICULTY`, `CREATE_IDENTITY`, `PAUSE_HABIT`, `ARCHIVE_HABIT`, `RESUME_HABIT`).
       - `checkCommandCapability(action: string)`: evaluates `SYS_COMMAND_CAPABILITY_CHECK_001` via `ruleEngine.ts`. If unsupported, returns `{ supported: false, rulesApplied: ['SYS_COMMAND_CAPABILITY_CHECK_001'] }`.
       - `validateCommand(command: DispatchedCommand, options?: { caller?: CommandActor })`:
         - Checks `command.idempotencyKey` (non-empty string, 4..128 chars).
         - Checks action capability.
         - Validates action-specific payload:
           - `CREATE_HABIT`: `title` (trimmed 1..100 chars), `behavior` (trimmed 1..200 chars), `minimumAction` (trimmed 1..100 chars), `normalTarget` (trimmed 1..100 chars), `frequency` in valid frequencies. If `frequency === 'custom'`, `customSchedule.weekdays` must be array of ints 0..6 (len 1..7). Valid `cueType`. If `cueTime` present, validates `^([01]\d|2[0-3]):[0-5]\d$`.
           - `UPDATE_HABIT`: `habitId` (non-empty string), `updates` (object). Explicitly rejects forbidden keys: `status`, `streakCount`, `bestStreak`, `totalEvidenceVotes`, `lastCompletedDate`. Permits only: `title`, `behavior`, `minimumAction`, `normalTarget`.
           - `LOG_HABIT`: `habitId` (non-empty string), `completedAt` (valid date parse), optional `durationMinutes` ($\ge 0$).
           - `START_RECOVERY`: `habitId` (non-empty string), `reason` (valid FrictionCategory).
           - `DELETE_HABIT`: `habitId` (non-empty string). If caller is `'ai'` and `!command.confirmed`, rejects with `"Destructive command DELETE_HABIT requires explicit user confirmation"`.
           - `DISMISS_INTERVENTION`: `interventionId` (non-empty string), `reason` in `['acted', 'dismissed', 'expired']`.
           - `ADJUST_DIFFICULTY`: `habitId` (non-empty string), `direction` in `['easier', 'harder']`, `newMinimumAction` (trimmed 1..100 chars).
           - `CREATE_IDENTITY`: `statement` (trimmed 1..200 chars).
           - `PAUSE_HABIT` / `ARCHIVE_HABIT` / `RESUME_HABIT`: `habitId` (non-empty string), `actor` in `['user', 'engine']`, `reason` (trimmed 1..200 chars). If `ARCHIVE_HABIT` from `'ai'` without confirmation, rejects.
         - Returns `CommandValidationResult`: `{ valid: boolean, errors: string[], rulesApplied: string[] }`.
    2. Create `src/commands/commandExecutor.ts`:
       - In-memory bounded LRU / FIFO idempotency cache (max 200 items, 15-minute TTL).
       - Handler registry: `registerCommandHandler<A extends CommandAction>(action: A, handler: (payload: CommandPayload<A>, meta: { idempotencyKey: string; actor: CommandActor }) => Promise<{ entityId?: string; message: string; rulesApplied?: string[] }> | { entityId?: string; message: string; rulesApplied?: string[] })`.
       - `executeCommand<A extends CommandAction>(command: DispatchedCommand<A>): Promise<CommandExecutionResult>`:
         - Runs `validateCommand`. If invalid, returns `{ success: false, message: '', error: errors.join('; '), requestId: command.idempotencyKey, rulesApplied }`.
         - Checks idempotency cache. If key exists and TTL not expired, returns cached result with `rulesApplied` including `'SYS_IDEMPOTENT_COMMAND_001'`.
         - Executes registered handler in `try/catch`.
         - On success: packages `CommandExecutionResult`, caches in idempotency map, emits `COMMAND_EXECUTED` event on `eventBus`, returns result.
         - On catch: logs via `logger.error`, emits `COMMAND_FAILED` on `eventBus`, returns `{ success: false, message: '', error: err.message, requestId: command.idempotencyKey }`.
       - Exports `clearIdempotencyCache()` for testing and maintenance.
  </action>
