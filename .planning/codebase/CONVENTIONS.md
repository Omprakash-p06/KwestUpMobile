# Conventions

**Analysis Date:** 2026-09-28

## Code Style (lint, formatting, TS strictness)

- **Linter:** ESLint 9 (`eslint@^9.39.4`) with dual config files kept in sync: `.eslintrc.js` (legacy `eslintrc` format, `root: true`) and `eslint.config.js` (flat config). Both target `**/*.{js,jsx}` with `@babel/eslint-parser` (ECMAScript 2021, `sourceType: module`, JSX on, `babelOptions.configFile: ./babel.config.js`).
- **Plugins / extends:** `eslint:recommended` + `plugin:react/recommended`, plugins `react`, `react-native`, `react-hooks`. `settings.react.version: 'detect'`.
- **Key rules (identical in both configs):**
  - `react/react-in-jsx-scope: off` (flat config only; new JSX transform, React 19) — `App.js`, `src/components/*.js`, `src/screens/*.js` import `React` anyway for hooks/context.
  - `react/prop-types: off` — no propTypes anywhere; components use destructured props with inline defaults (e.g. `TaskListScreen({ tasks = [], ... })` in `src/screens/TaskListScreen.js`).
  - `react-native/no-unused-styles: warn`, `react-native/no-inline-styles: warn`, `react-native/no-color-literals: warn` (flat config only), `react-native/no-raw-text: off`, `react-native/sort-styles: off`.
  - `react-hooks/rules-of-hooks: error`, `react-hooks/exhaustive-deps: warn`.
  - `no-unused-vars: ['warn', { argsIgnorePattern: '^_' }]` — `_`-prefixed args intentionally ignored.
  - `no-console: warn` — `console.log`/`console.error` with emoji prefixes are the de-facto logging convention (see below); lint warns but `npm run lint` (`eslint .`) and `check.bat` still gate on warnings-as-pass (no `--max-warnings 0`).
- **Ignore patterns:** `node_modules/`, `.expo/`, `dist/`, `web-build/`, `android/`, `ios/`, `KwestUpPC/` (+ `assets/**` in flat config).
- **Test override:** `eslint.config.js` declares Jest globals (`describe`, `it`, `test`, `expect`, `beforeEach/afterEach`, `beforeAll/afterAll`, `jest`) as `readonly` for `__tests__/**/*.{js,jsx}` and `*.test.{js,jsx}`.
- **Formatting:** No Prettier config detected (no `.prettierrc*`, no `prettier` in `package.json`). Style is enforced by convention: double quotes, semicolons, 2-space indent, trailing commas — see `src/utils/dateUtils.js`, `src/utils/taskMutations.js`, `src/components/TaskCard.js`.
- **Babel:** `babel.config.js` uses `presets: ['babel-preset-expo']` + `plugins: ['react-native-reanimated/plugin']` (Reanimated plugin must stay last). ESLint parser and Jest (`babel-jest` via `jest-expo`) both consume this file.
- **TypeScript strictness:** Effectively non-strict / opt-in. `tsconfig.json` is 4 lines (`{} + extends: expo/tsconfig.base`) with no `strict`, `noImplicitAny`, or `include` overrides. Codebase is `.js`/`.jsx` only (`App.js`, `src/**/*.js`); `@types/react`, `@types/jest`, `typescript@~5.8.3` are dev-only for editor/Jest support. JSDoc `@param`/`@returns` blocks are the typing convention — see `src/utils/dateUtils.js:8-13`, `src/utils/taskMutations.js:13-20`, `src/utils/syncService.js:24-31`, `src/utils/exportService.js:12-19`.

## Naming (files, components, services, tests)

- **Files:** `PascalCase.js` for components, screens, contexts, navigators (`src/components/TaskCard.js`, `src/components/TaskEditModal.js`, `src/screens/TaskListScreen.js`, `src/context/TaskContext.js`, `src/navigation/AppNavigator.js`); `camelCase.js` for utilities/services (`src/utils/dateUtils.js`, `src/utils/taskMutations.js`, `src/utils/syncService.js`, `src/utils/exportService.js`, `src/utils/fileStorage.js`, `src/utils/vaultService.js`, `src/utils/billingStorage.js`). Theme files lowercase (`src/theme/colors.js`, `src/theme/styles.js`). Widget handler is the one exception: `widgets/widget-task-handler.tsx`.
- **Components:** PascalCase named exports, one component per file (`export const TaskCard = ({ task, ... })` in `src/components/TaskCard.js:8`; `export const TaskListScreen = ({ tasks = [], ... })` in `src/screens/TaskListScreen.js:10`). Shared primitives use `Custom*` prefix (`CustomButton`, `CustomCard`, `CustomTextInput`, `CustomDateTimePicker`, `CustomSegmentedButtons`, `CustomSwitch`, `CustomBadge` in `src/components/`). Glassmorphism variants use `LiquidGlass*` (`LiquidGlassCard`, `LiquidGlassBackground`).
- **Contexts:** `*Context.js` + `*Provider` + `use*` hook in `src/context/` (`TaskContext.js` → `TaskProvider`/`useTasks`, `VaultContext.js` → `VaultProvider`, `BillingContext.js` → `BillingProvider`, `BirthdayContext.js` → `BirthdayProvider`). Handlers inside providers use `handle*` prefix (`handleSaveTask`, `handleCompleteTask`, `handleToggleSubtask`, `handleCreateList` in `src/context/TaskContext.js:142-239`).
- **Services / utils:** camelCase named exports, verb-first (`getLocalDateString`, `parseLocalDate`, `isSameLocalDay` in `src/utils/dateUtils.js`; `calculateNextRecurrence`, `toggleTask`, `completeTask`, `saveTask`, `deleteTask`, `toggleSubtask`, `createTaskList` in `src/utils/taskMutations.js`; `validateSyncConfig`, `validateSyncPayload`, `pingSyncServer`, `performSync` in `src/utils/syncService.js`; `encryptBackup`, `decryptBackup`, `exportArchive`, `importArchive` in `src/utils/exportService.js`; `isUserDataKey`, `clearAllCaches`, `migrateUserDataIfNeeded` in `src/utils/storage.js`).
- **Storage keys:** `kwestup_<domain>_<version>` (`kwestup_data_v7.0`, `kwestup_userName_v7.0`, …; constants `APP_VERSION = "v3.5.0"`, `STORAGE_VERSION = "v7.0"` in `src/utils/storage.js:3-4`).
- **Tests:** Mirror source name + `.test.js` under `__tests__/`: `__tests__/unit/dateUtils.test.js`, `__tests__/unit/taskMutations.test.js`, `__tests__/unit/taskContext.test.js`, `__tests__/unit/syncService.test.js`, `__tests__/unit/exportImportService.test.js`, `__tests__/unit/storageMigration.test.js`, `__tests__/unit/vaultAndFileStorage.test.js`, plus `__tests__/phase12-widget-logic.test.js` (tagged `[12-P1]`–`[12-P10`) and `__tests__/setup/jest.setup.test.js` (mock smoke test). `jest.config.js:24` matches only `**/__tests__/**/*.test.[jt]s?(x)`.

## File Organization

- **Top level:** `App.js` (1293-line composition root: providers, navigation, boot/migration orchestration) + `index.js`; `src/` (app code), `__tests__/` (all tests), `widgets/` (Android widget), `android/`, `assets/`, `coverage/` (committed Jest output — `clover.xml`, `coverage-final.json`, `lcov.info`, `lcov-report/`).
- **`src/components/`** — reusable presentational components only (14 files: `TaskCard.js`, `TaskEditModal.js`, `AIAssistant.js`, `QRScannerModal.js`, `TimerLockoutOverlay.js`, …). Import theme via `useTheme()` from `react-native-paper` + `src/theme/colors.js`; cross-import siblings relatively (`./LiquidGlassCard` in `src/components/TaskCard.js:6`).
- **`src/screens/`** — 9 route screens (`DashboardScreen.js`, `TaskListScreen.js`, `DailyTasksScreen.js`, `BillingScreen.js`, `BirthdaysScreen.js`, `FocusTimerScreen.js`, `NotesScreen.js`, `SearchScreen.js`, `SettingsScreen.js`). Screens are prop-driven (tasks, theme, callbacks) rather than importing contexts directly; local UI state via `useState`/`useRef` (e.g. `TaskListScreen.js:24-36`).
- **`src/context/`** — 4 providers (`TaskContext.js`, `VaultContext.js`, `BillingContext.js`, `BirthdayContext.js`). New pattern (exemplified by `src/context/TaskContext.js`): thin state shell delegating all transformations to pure functions in `src/utils/taskMutations.js:5-14`, with side effects (notifications, haptics, `AsyncStorage`) at the provider edge.
- **`src/utils/`** — 13 pure-ish service modules; new/hardened core is `dateUtils.js` (sole date authority — never slice ISO strings) + `taskMutations.js` (framework-agnostic, shared with `widgets/widget-task-handler.tsx`). Others: `storage.js` (versioning/migration), `syncService.js`, `exportService.js`, `vaultService.js`, `fileStorage.js`, `notifications.js`, `billingStorage.js`, `billingNotifications.js`, `aiService.js`, `diagnostics.js`, `vaultImport.js`.
- **`src/navigation/`** — `AppNavigator.js` + `CustomDrawerContent.js`. **`src/theme/`** — `colors.js` (theme objects) + `styles.js` (shared `StyleSheet`s, `injectFontFamily` helper imported by screens, e.g. `src/screens/TaskListScreen.js:8`).
- **Import order convention** (see `App.js:1-60`, `src/context/TaskContext.js:1-20`, `src/utils/exportService.js:1-8`): (1) React/React-Native/Expo/third-party, (2) sibling components, (3) theme/navigation/context, (4) utils. All relative imports use `./`/`../` — no path aliases configured.
- **JSDoc file headers:** Every new/hardened module opens with a banner comment stating ownership and contract (`src/utils/dateUtils.js:1-6`, `src/utils/taskMutations.js:1-10`, `__tests__/setup/jest.setup.js:1-6`).

## Error Handling & Validation Patterns

- **Pure validators throw descriptive `Error`s; callers/tests assert on message substrings:** `validateSyncConfig` / `validateSyncPayload` in `src/utils/syncService.js:32-70` (`missing or invalid IP`, `is malformed`, `out of bounds`, `missing or insufficiently long security token`, `Malformed server response`, `missing required 'notes' array`); `decryptBackup` normalizes all crypto failures to `Unable to decrypt archive. Please verify the passphrase.` (`src/utils/exportService.js:57+`); `performSync` maps offline → `Unable to connect to the PC Sync Server.` and 401/403 → `Authorization Forbidden: … Please re-scan.` — all pinned by `__tests__/unit/syncService.test.js` and `__tests__/unit/exportImportService.test.js`.
- **Defensive date contract:** `src/utils/dateUtils.js` never throws — invalid input yields `''` (`getLocalDateString`) or `Invalid Date` (`parseLocalDate`), with regex + component round-trip validation so `2023-02-29`/`2026-13-01`/ISO datetimes/booleans/objects are rejected; `parseLocalDate` clones `Date` inputs instead of aliasing (`src/utils/dateUtils.js:63-86`). Recurrence fallback in `src/utils/taskMutations.js:24-26` resets unparseable `dueDate` to `now` rather than propagating `NaN`.
- **Async boundaries use try/catch → log → safe default:** `clearAllCaches` returns `true`/`false` (`src/utils/storage.js:24-65`); `migrateUserDataIfNeeded` skips when current-version key exists (`src/utils/storage.js:68-77`); provider `refreshTasksFromStorage` JSON-parses inside try/catch with structural-equality guard before `setState` (`src/context/TaskContext.js:61-103`); `toggleTaskComplete` chains `scheduleDueDateNotification(...).then(...)` without letting notification failure break the state update (`src/context/TaskContext.js:126-140`); `Haptics` calls wrapped in bare `try { } catch { }` (`src/context/TaskContext.js:148-152`).
- **Destructive-action guards:** list deletion protects `default_inbox` (`src/utils/taskMutations.js:286-292`); task deletion routes through optional confirmation (`customConfirm || showConfirmationDialog`, else immediate) and cancels the task's notification (`src/context/TaskContext.js:160-181`); note/title sanitization strips filesystem-unsafe characters (`__tests__/unit/vaultAndFileStorage.test.js:96-104`); `validateSyncPayload` requires `notes`/`tasks`/`birthdays` arrays to prevent accidental wipes (`src/utils/syncService.js:80+`).
- **Logging convention:** emoji-prefixed `console.log` for lifecycle (`🔄 Synchronized tasks…`, `🧹 STARTING COMPREHENSIVE CACHE CLEAR…`, `📦 Data exists…`) and `console.error` with `❌` prefix for failures (`❌ CACHE CLEAR FAILED:`, `❌ Encryption failed:`, `❌ Failed to refresh tasks from storage:`). No logging library; `no-console: warn` tolerates this.
