    Create `src/utils/dateUtils.js` exporting:
    1. `getLocalDateString(input = new Date())`: Returns `'YYYY-MM-DD'`. If input is already a valid `YYYY-MM-DD` string, returns it directly. If input is a Date, number, or ISO string, extracts `getFullYear()`, `getMonth() + 1`, and `getDate()` zero-padded. Returns `''` on invalid input.
    2. `getYesterdayLocalDateString(input = new Date())`: Decrements input by 1 calendar day and returns `YYYY-MM-DD`.
    3. `getTomorrowLocalDateString(input = new Date())`: Increments input by 1 calendar day and returns `YYYY-MM-DD`.
    4. `getLocalMonthString(input = new Date())`: Returns `YYYY-MM`.
    5. `getLocalMonthDayString(input = new Date())`: Returns `MM-DD`.
    6. `parseLocalDate(dateStr)`: Parses `YYYY-MM-DD` using `new Date(year, month - 1, day, 0, 0, 0, 0)` so the resulting Date object is at midnight local time rather than UTC midnight.
    7. `isSameLocalDay(d1, d2)`: Returns boolean indicating whether two dates/strings/timestamps fall on the same local calendar day.
  </action>

  </verify>
