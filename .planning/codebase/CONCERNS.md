## Security & Privacy

- **Live storage is plaintext AsyncStorage (on-device guarantee is partial).** Tasks/birthdays/billing/habits/events/vault configs sit unencrypted in keys enumerated by `src/utils/storage.js:isUserDataKey` (`kwestup_data_v7.0`, `kwestup_billing_*`, `kwestup_habits_v1`, `kwestup_behavior_events_v1`, `kwestup_identities_v1`, `kwestup_rewards_v1`). Only the export archive is encrypted. Zero `expo-secure-store`/`SecureStore` usage repo-wide (verified by grep). Rooted-device/backup read exposes PII + financial data. Mitigation: `src/utils/logger.js:38` redaction regex keeps note bodies/tokens out of logs — keep it updated. Next: SecureStore for tokens/passphrases; evaluate encrypted storage for billing/PII.
- **Backup encryption v1 fallback is weak.** `src/utils/exportService.js:84-92` transparently accepts v1 (static salt `4b77657374557053616c745f7632`, PBKDF2 1000 iterations, salt-as-IV). New archives are v2 (`encryptBackup:21-47`, random 16B salt/IV, PBKDF2-SHA256 100k, AES-256) — good — but any v1 archive in the wild is cheap to brute-force and `decryptBackup:70` honors attacker-supplied `iterations`. Next: warn on v1 import + offer re-export to v2; clamp min iterations; sunset v1.
- **LAN sync travels over cleartext HTTP with a 6-char token minimum.** `src/utils/syncService.js:67` (`token.trim().length < 6`), `baseUrl = http://...` at `:110,137`, `Authorization: Bearer` at `:169`. `pingSyncServer` sends a dummy `ping-token-check` and skips auth (`:109-117`). QR-scanned config (`src/components/QRScannerModal.js`, `src/screens/SettingsScreen.js:734`) is a token-injection surface; validation allows hostnames/IPv6 (`:46-56`). Next: ≥32-char random token minimum, prefer HTTPS/document LAN-cleartext risk in UI, validate QR shape, add auth-failure throttling. Note `android/.../AndroidManifest.xml` sets `usesCleartextTraffic=true` + `allowBackup=true` — required for LAN sync but widens exposure; confirm no sensitive key is covered by auto-backup.
- **Filename sanitization incomplete (vault/file layer).** `src/utils/fileStorage.js:33-54` replaces `/\\?%*:|"<>` but permits `..` segments and doesn't constrain folder names equally; `src/utils/vaultImport.js` and import-restore (`src/utils/exportService.js:274+`) write attacker-influenced (import/sync) filenames. Next: central `sanitizePathSegment` (strip `.`/`..`, leading `-`, controls, cap length), apply to folder+title+vault name, unit-test `../`/absolute/unicode-overlong inputs, verify delete paths can't escape vault root.
- **LLM prompt-injection → task-creation chain.** Untrusted note/task content interpolated into prompts (`src/utils/aiService.js:615+,947+,1021+`); extracted `TODO:`/`FIXME:` lines (`:516-517`) flow into task creation (`src/navigation/AppNavigator.js:112-387`). Model pinned to HuggingFace commit (`aiService.js:23-28`) — URL/commit rot kills downloads. Next: delimit untrusted content in prompts, validate/cap extracted tasks, require confirmation before model output executes destructive actions.
- **Permissions + externals.** Manifest requests `CAMERA`, `RECORD_AUDIO`, `SYSTEM_ALERT_WINDOW`, `RECEIVE_BOOT_COMPLETED` (`android/app/src/main/AndroidManifest.xml`) — audit each is still needed (camera=QR sync, audio=llama.rn?). `src/utils/diagnostics.js:24,65,132` fetches `httpbin.org`, `api.github.com`, `https://api.kwestup.com/telemetry` (last is dead code — verify no real telemetry exfiltration, since opt-in flag `kwestup_telemetry_optin` in `src/screens/SettingsScreen.js:457` must stay meaningful). `npm audit`: 73 vulns (transitive `ws` via devtools, dev-only) — schedule CI `npm audit --audit-level=high`.

## Reliability Risks

- **Boot-guard protects but can't heal.** `src/context/TaskContext.js:104-120`, `src/context/HabitContext.js:100-103`: corrupt `kwestup_data_v7.0` (killed mid-write) → `JSON.parse` throws → empty defaults rendered with only a log line; user perceives data loss. `migrateUserDataIfNeeded` (`src/utils/storage.js:74-192`) may rescue from legacy key if present — not guaranteed.
- **Bare `JSON.parse` across storage/sync/AI paths.** `src/utils/vaultService.js:51`, `src/utils/billingStorage.js:22`, `src/context/TaskContext.js:81,108,136`, `src/context/HabitContext.js:80-96`, `src/utils/aiService.js:296,720,806`, `src/utils/exportService.js:62,81,92`, `src/services/notificationService.ts:155` — most fall back to `[]`/`{}` (silent data drop); export/import collapses all causes to "Unable to decrypt archive", misleading users.
- **Destructive import pipeline.** `src/utils/exportService.js:205-385`: clear-storage → restore-storage → restore-vault-files with no pre-restore snapshot; mid-restore failure (wrong passphrase detected late, disk full, kill) leaves partial state.
- **Notification fire-and-forget.** `src/context/TaskContext.js:217` (`.catch` warn-and-continue), `src/utils/billingNotifications.js:78-87` (`return null`), recurring-vs-one-shot exemption design in `src/services/notificationService.ts` (subtle; a "unify paths" refactor breaks Feb-29/advance semantics). Permission revoked after scheduling → reminder silently never fires.
- **Vault dual source of truth.** Configs in AsyncStorage vs bodies on disk (`src/utils/vaultService.js`, `src/utils/fileStorage.js`, `src/utils/vaultImport.js`, `src/context/VaultContext.js`, legacy `kwestup_vaults_v5.0`) can desync; no boot reconcile pass.
- **Whole-snapshot `JSON.stringify` dirty-check per render.** `src/context/TaskContext.js:95-100`, `src/context/HabitContext.js:161-170` — O(n) serialization on every keystroke before debounced write (≤1s/400ms); jank + higher corrupt-on-kill window as corpus grows.
- **Widget headless + native fragility.** `widgets/*.tsx` (5 widgets, 30-min `updatePeriodMillis` in `app.json:52-115`), `widget-task-handler.tsx` double-tap/headless paths (recent WR-02/WR-03/WR-05 fixes in `git log --oneline -20`), excluded from typecheck, no rendering tests. `expo.useLegacyPackaging=true` covers 16KB page-size (Android 16) via install-time extraction — good mitigation, but adds install size/time; verify on 16KB devices.

## Scalability Limits

- **Single-key AsyncStorage documents.** Entire task corpus in one `kwestup_data_v7.0` value; habits/events/rewards in four more keys. Fine for hundreds of items; multi-MB values hit parse/hydration cliffs and raise corrupt-on-kill risk. Path: cap/paginate history, keep note bodies on filesystem, consider `expo-sqlite` past low thousands.
- **Event caps lose long-term signal by design.** Ring buffer `MAX_EVENT_BUFFER_SIZE = 100` (`src/behavior/eventBus.ts:10,164-265`, FIFO + deep-freeze) and persisted `MAX_PERSISTED_BEHAVIOR_EVENTS = 500` FIFO (`src/context/HabitContext.js:38-39,262-263`); notification history (`kwestup_notification_history_v1`, `src/services/notificationService.ts:33,153+`) is append-only with **no** cap — unbounded growth. Streak math derives from habits (safe); consistency/automaticity scores (`improvementEngine.ts`) degrade beyond window. Path: cap history (30d/500 entries, prune on write); aggregate-then-evict if multi-year analytics ever needed.
- **On-device LLM memory ceiling.** `qwen2.5-0.5b` (~491MB, `src/utils/aiService.js:22-56`) + 5-min idle/background unload + ~5000-char prompt clamps (`:947-948`); inference alongside large notes risks OOM kills on low-RAM devices. `largeHeap=true` in manifest papers over pressure. Path: keep unload behavior, stream hash verification, chunk large-note summarization, graceful low-memory AI-off fallback.

- **Zero component/screen tests.** All 9 `src/screens/*.js` + `App.js` boot + `widgets/*` rendering untested; only `ErrorBoundary` has a smoke test. 20 suites pass (utils/engines/contexts) but the 2014-line `NotesScreen` and 1089-line `App.js` boot are blind spots. Priority: high (boot), med (top-2 screens smoke tests).
- **Restore/migration failure modes untested.** `exportImportService.test.js`, `storageMigration.test.js`, `vaultAndFileStorage.test.js` cover happy paths/helpers — no mid-restore-kill, hostile-filename (`../`), corrupt-JSON, or legacy-version-matrix cases. Priority: high (highest-stakes flow).
- **Sync security paths thin.** `syncService.test.js` covers validation shape; missing: short/weak token rejection upgrade, `http` cleartext documentation, malformed-QR injection, auth-lockout, oversized-payload timeout (10s budget at `syncService.js:172`). Priority: med.
- **AI output adversarial cases thin.** `aiService.test.js` + `aiAssistant-smoke.test.js` only; non-JSON/truncated/oversized model output, OOM fallback, and prompt-injection task-creation chain untested. Priority: med.
- **Reminder end-to-end absent.** `notificationService.test.ts` (largest suite, 908 lines) is strong at unit level; OS firing/Doze/exact-alarm, deep-link handling, billing/birthday null-return paths, Feb-29 edges have no device-level coverage. Priority: med.
