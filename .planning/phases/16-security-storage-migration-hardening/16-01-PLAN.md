       - Generate 128-bit random salt (`CryptoJS.lib.WordArray.random(16)`).
       - Generate 128-bit random IV (`CryptoJS.lib.WordArray.random(16)`).
       - Derive 256-bit AES key using PBKDF2: `iterations: 100000`, `keySize: 256/32`, `hasher: CryptoJS.algo.SHA256`.
       - Encrypt `JSON.stringify(payloadObj)` using AES-CBC with `{ iv: iv }`.
       - Return JSON envelope string:
         ```json
         {
           "v": 2,
           "kdf": "PBKDF2",
           "hasher": "SHA256",
           "iterations": 100000,
           "salt": CryptoJS.enc.Hex.stringify(salt),
           "iv": CryptoJS.enc.Hex.stringify(iv),
           "ciphertext": encrypted.toString()
         }
         ```
    2. In `decryptBackup(encryptedText, passphrase)`:
       - Attempt to parse `encryptedText` as JSON envelope.
       - If envelope has `v === 2` and valid `salt`, `iv`, and `ciphertext`:
         - Parse `salt` and `iv` from hex.
         - Derive key using PBKDF2 with `envelope.iterations || 100000` and SHA-256.
         - Decrypt `envelope.ciphertext` with `{ iv }`.
         - Parse and return plaintext JSON.
       - If not a v2 envelope (or JSON parse fails), fall back to legacy v1:
         - `salt = CryptoJS.enc.Hex.parse("4b77657374557053616c745f7632")`
         - `key = CryptoJS.PBKDF2(passphrase, salt, { keySize: 256/32, iterations: 1000 })`
         - Decrypt with `{ iv: salt }`.
         - Parse and return plaintext JSON.
       - Catch errors and throw: `"Unable to decrypt archive. Please verify the passphrase."`
