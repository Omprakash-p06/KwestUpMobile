  <action>
    Create `src/utils/taskMutations.js` with pure functions (no React, no hooks, no native side effects):
    1. `calculateNextRecurrence(task, now)`:
       - Parses `currentDueDate = task.dueDate || now`. If invalid, falls back to `now`.
       - Computes next due date:
         - `daily`: +1 day
         - `weekly`: +7 days
         - `monthly`: +1 month
         - `progressive`: +1 day, and regex-increments the last number in title (e.g. `match(/\d+(?!.*\d)/)` -> `num + 1`), or appends `" - 2"` if no number exists.
       - Returns a spawned task object with:
         - `id`: `Date.now().toString() + Math.random().toString(36).slice(2)`
         - `title`: `newTitle`
         - `completed`: `false`
         - `completedDate`: `null`
         - `completedAt`: `null`
         - `dueDate`: `date.toISOString()`
         - `createdAt`: `now`
         - `updatedAt`: `now`
         - `notificationId`: `null`
         - Inherits all other task properties (e.g. `listId`, `important`, `recurrence`, `tags`).
    2. `toggleTask(tasks, taskId, options = {})`:
       - `now = options.now || new Date().toISOString()`
       - `todayDate = options.todayDate || getLocalDateString()`
       - Iterates over `tasks`:
         - For target task:
           - `nextCompleted = !task.completed`
           - If `nextCompleted && task.recurrence && task.recurrence !== "none"`:
             - Compute `spawned = calculateNextRecurrence(task, now)`.
             - Push `spawned` into updated list (parent is removed, matching both `App.js` and widget).
           - Else:
             - Push updated task with `completed: nextCompleted`, `completedDate: nextCompleted ? todayDate : null`, `completedAt: nextCompleted ? now : null`.
         - For other tasks: push unchanged.
       - Returns `{ updatedTasks, toggledTask, spawnedTask }`.
    3. `completeTask(tasks, taskId, options = {})`:
       - Explicitly marks task completed with `completed: true`, `completedDate: todayDate`, `completedAt: now`.
    4. `saveTask(tasks, taskData, options = {})`:
       - If `taskData.id` exists in `tasks`, updates that task in place.
       - Else creates new task with generated ID and appends.
       - Enforces default `listId: "default_inbox"`.
    5. `deleteTask(tasks, taskId)`:
       - Filters out task by ID. Returns `{ updatedTasks, deletedTask }`.
    6. `toggleSubtask(tasks, taskId, subtaskIdx, options = {})`:
       - Toggles `subtasks[subtaskIdx].completed` and updates `completedAt`.
    7. `createTaskList(taskLists, name)`:
       - Appends `{ id: Date.now().toString(), name: name.trim(), createdAt: new Date().toISOString() }`.
    8. `renameTaskList(taskLists, listId, newName)`:
       - Updates list name if found.
    9. `deleteTaskList(taskLists, listId)`:
       - Filters out list (prevents deleting `"default_inbox"`).
  </action>
