    1. **Listener Storage & Wildcards:**
       - Use a `Map<DomainEventType, Set<DomainEventListener>>` for typed listeners.
       - Use a `Set<DomainEventListener<DomainEventType>>` for wildcard listeners (`subscribeAll`).
       - `subscribe<T>(type, listener)` returns an idempotent unsubscription function `() => void`.
       - `subscribeAll(listener)` returns an idempotent unsubscription function `() => void`.
    2. **Error Isolation (Fault Tolerance):**
       - In `emit(eventInput)`:
         - Generate `id` (`evt_${Date.now()}_${Math.random().toString(36).slice(2, 9)}`) and `timestamp` (`new Date().toISOString()`) if not supplied.
         - Construct defensive frozen event object `Object.freeze({ ...eventInput, id, timestamp })`.
         - Append to internal circular ring buffer (default max capacity 100, dropping oldest item if `buffer.length >= maxCapacity`).
         - Retrieve listener sets (type-specific and wildcard) as snapshots (`Array.from(...)` or shallow copy) to protect against listener set mutations during iteration.
         - Call each listener in an isolated `try / catch`. If a listener throws a synchronous exception, log with `logger.error("EventBus listener error:", { error: err.message, eventType: event.type })` and proceed to the next listener.
         - If a listener returns a Promise, attach `.catch((err) => logger.error("EventBus async listener error:", { error: err?.message, eventType: event.type }))` to isolate async rejections.
         - `emit` returns the created `DomainEvent` object.
    3. **Buffer & Utility Methods:**
       - `getRecentEvents(limit?: number): DomainEvent[]`: returns a shallow copy of recent events (optionally sliced to `limit`).
       - `clearBuffer(): void`: empties the telemetry ring buffer.
       - `clearListeners(): void`: clears all listeners (essential for test resets).
       - `listenerCount(type?: DomainEventType): number`: returns registered listener count for a type or total across all types.
    4. **React Hook (`useDomainEvent`):**
       - Implement `useDomainEvent<T extends DomainEventType>(type: T | null, listener: DomainEventListener<T>)`:
         - Uses `useRef` to store latest listener callback to avoid unnecessary resubscriptions when callback changes.
         - Uses `useEffect` to subscribe on mount and automatically call the unsubscribe token on unmount or type change.
    5. **Zero Raw Console Calls:**
       - Ensure zero `console.*` statements exist in `eventBus.ts`; all logs must use `logger.debug` and `logger.error`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Domain mutators to EventBus dispatcher | Mutators pass arbitrary payload data; invalid or throwing subscribers must not crash state mutations |
| EventBus subscribers to Event objects | Subscribers receive event references; must not mutate event payloads to corrupt live telemetry |
| In-memory ring buffer to process heap | High-frequency events must not cause unbounded memory growth |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-23-01 | Denial of Service | `eventBus` listeners | high | mitigate | Isolate all listener calls with try/catch and promise catch blocks; log errors via `logger.error` |
| T-23-02 | Denial of Service | telemetry ring buffer | medium | mitigate | Enforce strict circular buffer cap of 100 items with FIFO eviction on overflow |
| T-23-03 | Tampering | event payload objects | medium | mitigate | Deep-freeze or defensively clone event objects prior to listener invocation |
| T-23-04 | Information Disclosure | event bus logging | low | mitigate | Only log event type and entity ID; zero PII logged in structured logs |
| T-23-05 | Denial of Service | listener memory leak | medium | mitigate | Idempotent unsubscription tokens returned from `subscribe` and automatic hook cleanup |
</threat_model>
